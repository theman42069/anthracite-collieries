Anthracite Collieries of Pennsylvania

Send a Correction

Spotted a wrong date, have a photo of a colliery, or know someone who's missing from the memorial? Fill this in and it becomes a note to the person who keeps the map. Please say where the information comes from (a newspaper, a book, a family record, your own photo), so it can be checked.

What is it?

Please don't include phone numbers, home addresses or other private details. The note is posted publicly on GitHub.

“Send it on GitHub” opens a ready-filled issue on the project's GitHub page; you'll need a free GitHub account to post it. No account? Use “Copy the message instead” and paste it into a message to the map's keeper, for example in the Facebook group where you found this map.
